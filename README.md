# PDF 모아

Windows에서 PDF 합치기, 순서 변경, 나눠 저장, 미리보기와 간단한 편집을 제공하는 한국어 데스크톱 프로그램입니다.

## 사용

배포 ZIP을 압축 해제하고 `PDF-Moa.exe`를 실행합니다. Python 별도 설치는 필요 없습니다.
PDF를 창으로 끌어 놓고 목록에서 선택합니다. ↑/↓ 키로 미리보기를 넘기고, 드래그나 위/아래 버튼으로 순서를 변경합니다.
PDF를 목록 위로 끌어 오면 파란 선으로 들어갈 자리를 보여 주고 그 자리에 끼워 넣습니다. 목록 밖에 놓으면 끝에 추가합니다.
목록에는 페이지 썸네일이 표시되고(목록 위 **작게/크게**로 크기 선택), 편집한 페이지에는 `편집됨`이 붙습니다. 선택 상태에 맞지 않는 버튼은 흐리게 표시됩니다.
여러 파일을 한 번에 추가하면 파일 이름순(1, 2, 10…)으로 들어갑니다.
목록에서 **오른쪽 클릭**하면 맨 위/아래로, 왼쪽·180° 회전, 복제, 빈 페이지 넣기, 선택 뒤에 PDF 끼워 넣기 등을 쓸 수 있습니다.

| 단축키 | 동작 |
| --- | --- |
| Ctrl+O | PDF 추가 |
| Ctrl+S | 전체 합쳐서 저장 |
| Ctrl+Z / Ctrl+Y | 실행 취소 / 다시 실행 |
| Ctrl+A | 전체 선택 (목록에서) |
| Delete | 선택 페이지 빼기 (목록에서) |
| Alt+↑ / Alt+↓ | 선택 페이지 위/아래로 이동 |
| Alt+Home / Alt+End | 선택 페이지 맨 위/맨 아래로 |
| Home / End | 처음/끝 페이지 선택 |
| Ctrl+R / Ctrl+Shift+R | 오른쪽/왼쪽으로 90° 회전 |
| Ctrl+D | 선택 페이지 복제 |
| Ctrl+E 또는 더블클릭 | 글자·사진 편집 |
| Shift+F10 또는 메뉴 키 | 오른쪽 클릭 메뉴 |
| Enter (순서 번호 입력란) | 범위 선택 (1-3, 5 또는 1~3) |

글자 입력 창에서는 Enter가 줄바꿈, Ctrl+Enter가 적용, Esc가 취소입니다. 편집 창은 Ctrl+휠로 확대·축소합니다.
**나눠서 저장**은 한 쪽씩, N쪽씩, 범위별(목록 번호, 예: `1-3, 4-10`) 중에서 고릅니다. 고른 폴더 안에 `PDF_분리_날짜_시간` 폴더를 만들고 `001_원본이름_p1-2.pdf`처럼 저장합니다.
저장 이름은 첫 원본 이름을 따라 `○○_합침.pdf`, `○○_선택.pdf`로 제안합니다. 목록에 있는 원본 파일은 어떤 이름으로도 덮어쓰지 않습니다.
아래쪽 **파일별 책갈피**를 켜면 저장할 때 원본 파일이 시작되는 쪽마다 파일 이름으로 책갈피(목차)를 만듭니다. 원본 PDF에 있던 책갈피는 옮겨지지 않습니다.
암호 PDF는 틀리면 최대 3번까지 다시 묻습니다. 저장하지 않은 목록이 있으면 종료 전에 확인합니다.
마지막으로 쓴 폴더와 창 크기는 이 PC의 `%APPDATA%\PDF-Moa\settings.json`에만 기억합니다. 문서 내용은 저장하지 않습니다.

### 글자와 사진 편집

1. 편집할 페이지 **하나**를 선택하고 **글자·사진 편집**을 누릅니다. 빈 페이지에도 글자와 사진을 넣을 수 있습니다.
2. **글자 교체**, **글자 추가**, **사진 추가**, **글자 지우기** 중 하나를 고릅니다. **옮기기**로 이 창에서 넣은 글자·사진을 끌어 옮기거나 크기를 바꿀 수 있습니다.
3. 페이지 위에서 영역을 드래그합니다. 글자 가운데가 영역 안에 들어간 글자만 선택되고 파란색으로 표시됩니다.
4. 새 글자와 크기·색상 또는 사진을 지정합니다. 입력 창 오른쪽에 실제 PDF 결과가 실시간 표시됩니다. 사진은 영역 안에 비율을 유지해 가운데에 배치됩니다(정사각형 도장도 찌그러지지 않음).
5. 넣은 글자·사진은 **옮기기**에서 끌어 옮기고, 오른쪽 아래 모서리를 끌어 크기를 바꾸고, 두 번 클릭해 글자를 고치거나 사진을 바꿉니다. 오른쪽 클릭으로 그 항목만 지울 수 있고, 되돌리기(Ctrl+Z)는 옮긴 것도 되돌립니다.
6. 미리보기를 확인하고 **변경 적용**을 누른 뒤 메인 창에서 PDF를 저장합니다.

교체와 지우기는 흰색으로 덮는 방식이 아니라 선택한 글자를 실제로 삭제합니다. 선택하지 않은 글자는 지우지 않으며, 그렇게 지울 수 없는 문서는 안내 후 적용하지 않습니다.
원래 글자의 시작점과 각 줄의 기준선을 유지합니다. 드래그 박스의 모서리로 글자를 옮기지 않습니다.
원래 줄 수보다 줄이 많거나 영역 너비를 넘으면 적용하지 않으므로 미리보기 안내에 따라 조절하세요. 수평·90도 방향을 지원하며 비스듬한 글자는 위치 보존을 위해 교체를 차단합니다.
선택한 PDF 글꼴을 PC의 설치된 글꼴과 정확한 이름으로 비교해 자동 선택합니다. 혼합 글꼴이나 불확실한 이름은 자동 확정하지 않습니다.
일치하지 않으면 설치 글꼴 검색·선택 또는 TTF/OTF/TTC/OTC 파일 추가를 사용하세요. 기본 한글 글꼴(Droid Sans Fallback)도 선택할 수 있습니다.
글꼴 파일은 사용자 PC에서만 읽으며 시스템 설치·업로드·프로그램 동봉을 하지 않습니다. 파일 추가는 해당 입력 창에서 적용됩니다.
글꼴의 OS/2 fsType에 따라 포함 금지·보기/인쇄 전용·비트맵 전용·알 수 없는 제한을 차단합니다. 정보 없는 글꼴과 가변 글꼴은 지원하지 않습니다.
글꼴은 쓴 글자만 PDF에 포함해 파일을 작게 유지합니다. 부분 포함 금지 글꼴은 전체를 포함합니다. 입력 문자를 지원하지 않는 글꼴도 안내 후 차단합니다.
이는 기술적인 제한 검사이며 상업적 이용 등 모든 이용조건을 판정하지는 않습니다. 글꼴 제공처의 이용조건을 확인하세요.
원래 글꼴을 찾더라도 자간·줄바꿈·문서 서식을 완벽히 재현하지는 않습니다.
영역에 글자가 들어가지 않으면 적용되지 않습니다. 영역을 넓히거나 글자 크기를 줄이세요.
휴대폰 사진은 찍은 방향대로 세워서 넣고, WebP 사진도 넣을 수 있습니다.
이미지로 스캔된 문서의 글자 교체와 OCR은 지원하지 않습니다.
복잡한 양식, 전자서명, 태그, 메타데이터 등을 포함하는 문서 전체의 민감정보 제거 도구는 아닙니다.
암호 PDF를 열 수 있지만 출력에는 원본 암호가 자동 적용되지 않습니다.
편집 내용은 메모리에만 유지되므로 종료 전에 저장하세요. 원본 파일은 변경하지 않습니다.
인터넷 업로드, 계정, 사용 분석 전송 기능은 없습니다.

## 소스 실행 및 빌드

Windows x64, Python 3.12, Tcl/Tk 포함 배포판을 사용합니다.

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
.\.venv\Scripts\python app.py
.\.venv\Scripts\python -m unittest test_fonts test_editing test_keyboard test_position test_live_preview test_ui test_fixes test_features
.\build.ps1
```

버전은 `app.py`의 `VERSION` 한 곳에만 있고, `prepare_editor_release.py`가 그 값을 읽어 릴리스 파일 이름과 문서에 씁니다.
빌드 결과는 `dist/PDF-Moa.exe`입니다. 실행 파일 아이콘은 `build.ps1`이 `icons.py`의 로고로 만들며, 화면 아이콘도 같은 파일의 SVG를 실행 중에 그립니다. 라이선스와 소스 제공 파일을 제외하고 실행 파일만 재배포하지 마세요.
업스트림 원본 소스 ZIP은 같은 릴리스의 `PDF-Moa-<버전>-upstream-source.zip`에서 제공합니다.
그 안에 PyMuPDF 1.26.7과 MuPDF 1.26.12의 공식 소스 아카이브, 빌드 스크립트, 제3자 소스가 포함되어 있습니다.
PyMuPDF 소스 빌드는 해당 아카이브의 README와 setup.py 지침을 따릅니다. Visual Studio C++ 및 SWIG 등이 필요합니다.
동봉한 MuPDF 소스 디렉터리를 `PYMUPDF_SETUP_MUPDF_BUILD`로 지정해 PyMuPDF 소스를 빌드할 수 있습니다.
