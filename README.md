# PDF 모아

Windows에서 PDF 합치기, 순서 변경, 분리, 미리보기와 간단한 편집을 제공하는 한국어 데스크톱 프로그램입니다.

## 사용

배포 ZIP을 압축 해제하고 `PDF-Moa.exe`를 실행합니다. Python 별도 설치는 필요 없습니다.
PDF를 창으로 끌어 놓고 목록에서 선택합니다. ↑/↓ 키로 미리보기를 넘기고, 드래그나 위/아래 버튼으로 순서를 변경합니다.

### 글자와 사진 편집

1. 편집할 페이지 **하나**를 선택하고 **글자·사진 편집**을 누릅니다.
2. **기존 글자 교체**, **글자 추가**, **사진 추가** 중 하나를 고릅니다.
3. 페이지 위에서 영역을 드래그합니다. 교체는 바꿀 글자 전체가 포함되도록 선택합니다.
4. 새 글자와 크기·색상 또는 사진을 지정합니다. 사진은 영역 안에 비율을 유지해 배치됩니다.
5. 미리보기를 확인하고 **변경 적용**을 누른 뒤 메인 창에서 PDF를 저장합니다.

교체는 흰색으로 덮는 방식이 아니라 선택 영역과 겹치는 텍스트를 삭제하고 새 텍스트를 삽입합니다.
새 글자는 MuPDF의 기본 한글 글꼴로 입력되며 원래 글꼴·자간·줄바꿈을 완벽히 재현하지 않습니다.
영역에 글자가 들어가지 않으면 적용되지 않습니다. 영역을 넓히거나 글자 크기를 줄이세요.
이미지로 스캔된 문서의 글자 교체와 OCR은 지원하지 않습니다.
복잡한 양식, 전자서명, 태그, 메타데이터 등을 포함하는 문서 전체의 민감정보 제거 도구는 아닙니다.
암호 PDF를 열 수 있지만 출력에는 원본 암호가 자동 적용되지 않습니다.
편집 내용은 메모리에만 유지되므로 종료 전에 저장하세요. 원본 파일은 변경하지 않습니다.
인터넷 업로드, 계정, 사용 분석 전송 기능은 없습니다.

## 소스 실행 및 빌드

Windows x64, Python 3.12, Tcl/Tk 포함 배포판을 사용합니다.

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
.\.venv\Scripts\python app.py
.\.venv\Scripts\python -m unittest test_editing test_keyboard
.\build.ps1
```

빌드 결과는 `dist/PDF-Moa.exe`입니다. 라이선스와 소스 제공 파일을 제외하고 실행 파일만 재배포하지 마세요.
업스트림 원본 소스 ZIP은 같은 릴리스의 `PDF-Moa-1.1.0-rc1-upstream-source.zip`에서 제공합니다.
그 안에 PyMuPDF 1.26.7과 MuPDF 1.26.12의 공식 소스 아카이브, 빌드 스크립트, 제3자 소스가 포함되어 있습니다.
PyMuPDF 소스 빌드는 해당 아카이브의 README와 setup.py 지침을 따릅니다. Visual Studio C++ 및 SWIG 등이 필요합니다.
동봉한 MuPDF 소스 디렉터리를 `PYMUPDF_SETUP_MUPDF_BUILD`로 지정해 PyMuPDF 소스를 빌드할 수 있습니다.
