[ ] 전체 합치기 / 선택 페이지만 저장 / 페이지별 분리가 정상

문제가 있으면: 누른 버튼, 오류 문구, PDF 페이지 수, 재현 순서
실제 문서에 개인정보가 있으면 문서를 보내지 말고 오류 내용만 알려주세요.

[ ] 글자 교체 후 저장하고 다른 뷰어에서 확인
[ ] 교체 전 문자열이 해당 영역에서 검색·복사되지 않음
[ ] 한글 글자 추가, 사진 추가, 편집 실행 취소 확인

[ ] 원래 글꼴 자동 선택 / 설치 글꼴 선택 / 글꼴 파일 추가 확인
[ ] 제한 글꼴·지원하지 않는 문자 입력 시 차단 확인

[ ] 단축키(Ctrl+O/S/Z/E/R, Delete, Alt+↑/↓)와 더블클릭 편집 동작
[ ] 글자 입력 창에서 Enter는 줄바꿈, Ctrl+Enter는 적용
[ ] 틀린 암호를 넣으면 다시 묻고(최대 3번), 맞는 암호로 열림
[ ] 오른쪽 클릭 메뉴: 맨 위/아래로, 왼쪽 회전, 복제, 빈 페이지, PDF 끼워 넣기
[ ] 나눠서 저장: 한 쪽씩 / 2쪽씩 / 범위별, 폴더와 파일 이름 확인
[ ] 글자 지우기 후 다른 뷰어에서 지운 글자가 검색되지 않음
[ ] 휴대폰으로 세로로 찍은 사진이 세워서 들어감
[ ] 탐색기에서 PDF를 목록 중간으로 끌어 오면 파란 선이 보이고 그 자리에 들어감
[ ] 파일별 책갈피를 켜고 합친 PDF를 다른 뷰어로 열어 책갈피 확인
[ ] 썸네일 작게/크게 전환, 프로그램을 다시 열어도 크기가 유지됨
[ ] 편집 창 옮기기: 넣은 도장·글자를 옮기고 크기를 바꾼 뒤 되돌리기
