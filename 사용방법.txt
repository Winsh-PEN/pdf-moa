PDF 모아 1.2.0-rc1 · Windows x64 · 2026-10-14

시작하기
ZIP 파일을 먼저 압축 해제한 뒤 PDF-Moa.exe를 실행하세요.
별도 Python 설치는 필요하지 않습니다. 관리자 권한 없이 실행하세요.
Windows 10/11 64비트용 테스트 배포판입니다. 다른 PC 호환성 확인 중입니다.
처음 실행할 때 내부 파일을 준비하므로 잠시 걸릴 수 있습니다.

파일 추가와 미리보기
PDF 추가 버튼 또는 탐색기에서 PDF 파일을 창에 끌어 놓습니다.
왼쪽 목록의 페이지를 클릭하면 오른쪽에 크게 표시됩니다.
목록을 클릭한 뒤 위/아래 화살표 키로 이전/다음 페이지를 확인합니다.
화살표 키는 선택만 이동합니다. 문서 순서는 바꾸지 않습니다.
+ / - 또는 Ctrl+마우스 휠로 확대·축소하고 화면 맞춤으로 되돌립니다.
확대한 페이지는 스크롤하거나 마우스로 끌어 이동할 수 있습니다.
가운데 경계선을 끌어 목록과 미리보기의 폭을 조절합니다.

순서 편집
페이지를 끌어 파란 선 위치에 놓거나 ▲ 위로 / ▼ 아래로를 누릅니다.
Ctrl/Shift와 마우스 클릭으로 여러 페이지를 선택해 함께 이동할 수 있습니다.
순서 뒤집기는 전체 목록의 순서를 반대로 바꿉니다.
90° 회전, 선택 삭제와 실행 취소를 지원합니다. 실행 취소는 최근 20회입니다.
범위 선택에는 현재 목록의 순서 번호를 입력합니다. 예: 1-3, 5, 8

저장
전체 합쳐서 저장: 목록의 현재 순서대로 하나의 PDF로 저장합니다.
선택 페이지만 저장: 선택한 페이지들을 목록 순서대로 한 PDF로 저장합니다.
페이지별로 분리 저장: 선택 페이지를 각 파일로 저장합니다.
선택이 없으면 전체를 분리하며, 지정 폴더 안에 새 하위 폴더를 만듭니다.
원본을 보호하기 위해 원본과 다른 파일명으로 저장하세요.

처리 방식과 제한
이 프로그램에는 PDF 업로드, 계정 로그인, 사용 분석 전송 기능이 없습니다.
PDF는 PC에서 처리하며 인터넷 연결 없이 사용할 수 있습니다.
편집 목록은 프로그램을 종료하면 사라집니다. 종료 전에 결과를 저장하세요.
암호 PDF는 열기 암호가 필요합니다. 저장 결과에는 암호가 자동 적용되지 않습니다.
원본 열기는 PC의 기본 PDF 프로그램으로 파일을 엽니다.
전자서명, 책갈피, 첨부파일과 일부 대화형 양식은 보존되지 않을 수 있습니다.
중요 문서는 저장 결과의 페이지 수·순서·표시 내용을 확인하세요.
코드서명 인증서가 적용되지 않은 테스트판입니다. 출처와 파일을 확인한 뒤 실행하세요.
보안 프로그램을 끄거나 경고를 무조건 우회하지 마세요.

배포
재배포 시 THIRD_PARTY_NOTICES.txt와 licenses 폴더를 함께 전달하세요.
이 파일의 설명은 제3자 라이브러리의 라이선스 원문을 대체하지 않습니다.


글자·사진 편집
1. 페이지 하나를 선택하고 글자·사진 편집을 누릅니다.
2. 기존 글자 교체 / 글자 추가 / 사진 추가를 선택합니다.
3. 페이지에서 영역을 드래그하고 새 글자나 사진을 지정합니다.
4. 변경 적용을 누르고 메인 창에서 결과 PDF를 저장합니다.
교체 영역은 바꿀 글자 전체를 포함해야 합니다. 글자 크기를 줄이거나 영역을 넓혀 맞추세요.
교체는 실제 텍스트를 제거합니다. PC에 일치하는 글꼴이 있으면 자동으로 선택됩니다.
일치하지 않으면 설치 글꼴 검색/선택 또는 글꼴 파일 추가(TTF/OTF/TTC/OTC)를 사용하세요.
포함 제한·지원 문자 검사를 통과해야 적용됩니다. 파일의 라이선스 정보 버튼도 확인하세요.
보기/인쇄 전용 등 제한 글꼴은 편집용으로 사용할 수 없습니다. 부분 포함 금지는 전체 포함으로 처리합니다.
이 검사는 모든 이용조건의 허가를 뜻하지 않으므로 제공처의 이용조건도 확인하세요.
원래 글꼴·자간·줄바꿈의 완벽한 보존과 스캔 이미지의 OCR 교체는 지원하지 않습니다.
선택 영역에 겹치는 다른 글자도 제거될 수 있으므로 미리보기를 확인하세요.
사진은 선택 영역에 비율을 유지해 들어갑니다. 잘못 배치하면 편집 취소 후 다시 추가하세요.
민감정보의 문서 전체 제거를 보장하는 보안 도구는 아닙니다.
